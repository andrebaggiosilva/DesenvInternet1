Nova Interface do Fogão

Neste Novo Conceito de Fogão os botões estão diretamente alinhados com as respectivas bocas
Desta maneira o usuário do fogão não precisa saber antecipadamente o mapemento entre bocas e botões
Para saber qual boca corresponde a qual botão de acionamento basta observar o alinhamento entre cada boca e o respectivo botão.

Este modelo foi pensado para eliminar as dúvidas que normalmente os usuários têm, inclusive as pessoas com baixa visão, para identificar o mapemento entre bocas e botões, já que foi observado que não existe um padrão único no mercado.

O fogão pode ser à gás ou elétrico. Se for um fogão à gas, cada botão tem a função quick-start que gera a faísca necessária para acender o fogo. Se for elétrico, basta girar para ligar. Isto facilita o uso para pessoas com limitação de uma mão somente.

Cada botão tem a forma de meia-lua, que favore a identificação do estado do acionamento, tanto de forma visual como tátil.

Manual de Utilização do Fogão

- Coloque uma panela sobre a boca desejada
- Localize o botão corresponde a boca, que estão alinhados verticalmente
- Para ligar basta girar o botão no sentido horário
- Se for modelo à gas, segure acionado até o fogo acender com a função quick-start
- Com o botão totalmente na vertical é fogo máximo, podendo ser reduzio para posições intermediárias
- Para desligar basta girar o botão no sentido anti-horário
